The site is being rebuilt as a rainy-night 3D walk at the foot of Tokyo Tower: Astro + React Three Fiber, with every 3D asset built by Python scripts driving Blender. `main` serves the old site until launch; v2 work lands on the `v2` branch.

**Before changing anything,** read `docs/spec/00-overview.md`. It holds every decision, contract, budget and workflow rule. When you're given a work package, also read its `docs/spec/wp-XX-*.md`, and edit only the paths it **Owns**.

A change to a contract (anything defined in the overview) goes into the overview in the same PR, listed under **Contract changes**.
