# WP-11: Street props art

**Depends on:** WP-02 · **Branch:** `wp-11-street-props` · **Wave:** 2
**Owns:** the `art/props/<name>.py` files listed below

## Goal

Build the props that make the street unmistakably a Tokyo backstreet at night. Each is a prop module (overview § 6.9) in the soft low-poly miniature style. WP-15 places them and bakes the lighting.

## Style rules (every prop)

- **Shapes:** simple and chunky, with bevels of at least 2 cm on boxy edges. Read the silhouette first and add detail second. No realistic textures; color comes from palette materials.
- **Glow:** `EMIT_` parts carry the cozy light (lamps, sign faces, windows), with strength 2–6.
- **Brands:** every brand is fictional. Japanese text goes through `ctx.text_jp`.
- **Colliders:** each prop has simple `COL_<name>_*` boxes covering what the character must not walk through.

## Steps

1. **Build each module** to the table and the style rules. Done when `python art/build.py prop:<name>` builds and validates with `--max-tris` set to its cap.
2. **Preview each one** with `python art/preview.py prop:<name>` (front and three-quarter views). Open each PNG and check it against the "What it is" description and the style rules. Done when every prop reads clearly at a glance and the glowing parts glow.
3. **Check scale** against the greybox (`public/models/street.glb` in `/dev/viewer`). The character is 1.15 m tall: vending machines about 1.85 m, the konbini about 4 m high, utility poles about 9 m. Done when the footprints match the matching `layout.json` entries within 10%.
